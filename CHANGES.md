# Что изменено

## Сборка на GitHub
- `app/build.gradle.kts`: убрана подпись `debugConfig`, которая требовала `debug.keystore` (его нет в репозитории). Debug подписывается стандартным ключом, release - своим из переменных `KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`, иначе тоже отладочным.
- `.github/workflows/build.yml`: новый workflow (JDK 17, Gradle 9.3.1, ubuntu-24.04, checkout@v5, setup-java@v5), собирает `assembleDebug` и выкладывает APK в Artifacts. В проекте нет `gradlew`, поэтому Gradle ставится отдельным шагом.
- `gradle.properties`: выключен configuration cache. `settings.gradle.kts`: имя проекта латиницей. Демо-тест теперь ждёт название «Медиатека».

## Плеер и источники
- Один общий ExoPlayer для приложения и сервиса уведомлений (`PlayerHolder`), фоновое воспроизведение и медиа-уведомление работают.
- Звук подбирается цепочкой способов с переходом к следующему при ошибке (`StreamResolver`): Audius, YouTube (Cobalt -> Piped через proxyUrl -> поиск в Audius), Яндекс (через ваш шлюз), запасной поиск того же трека в других каталогах.
- Поиск идёт во все источники параллельно, результаты появляются по мере ответа.
- Лента рекомендаций строится из избранного, ваших исполнителей и прослушиваний; обновляется по кнопке.
- Автопереход к следующему треку, повтор, перемешивание, «Мой микс», кубик.
- Скачивание реально скачивает файл (в приложение и, на Android 10+, в Загрузки/Mediateka).
- Настройки, вкус и недавние запросы сохраняются между запусками.

## Интерфейс
- `pressScale` переписан на `combinedClickable`: клики внутри списков больше не теряются, работает долгое нажатие (контекстное меню).
- Навбар: одна таблетка плавно переезжает между вкладками, подпись раскрывается по ширине.
- Стекло (`GlassSurface`): фон и контент внутри `hazeSource`, поэтому размытие реально видно; режим liquid с бликом, световой кромкой и подсветкой под пальцем.
- Снег снова движется. Шторка плеера больше не пропускает нажатия на навбар.
- Настройки: все переключатели и кнопки рабочие; «Сервисы» с вводом адресов, токенов и входом в Яндекс по коду. Шлюз Яндекса больше не зашит в код.
