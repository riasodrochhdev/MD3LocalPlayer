# Медиатека (MD3 Local Player)

Музыкальный плеер в стиле Material You, который работает прямо в браузере и ставится как приложение (PWA). Играет ваши локальные файлы и умеет подключать онлайн-каталоги.

Весь плеер: один `index.html` и service worker, без сборки и серверной части. Настройки и токены хранятся только в браузере (localStorage).

## Возможности

- Локальные файлы и папки, обложки и теги из файлов
- Лента рекомендаций, «Мой микс» и «Моя волна» (Яндекс)
- Избранное, очередь, перемешивание, повтор, скачивание
- 9 тем (включая AMOLED и моно), стекло, анимированный фон, свои обои (картинка, GIF, видео)
- Установка на телефон и компьютер, работа офлайн для интерфейса

## Источники музыки

| Сервис | Нужен свой воркер | Нужен аккаунт | Статус |
|---|---|---|---|
| Локальные файлы | нет | нет | работает |
| Audius | нет | нет | работает |
| YouTube | желательно | нет | зависит от Piped / воркера |
| Яндекс Музыка | да (`worker.js`) | да | работает |
| SoundCloud | да (`sc-worker.js`) | нет | работает, если SoundCloud не блокирует IP воркера |
| Spotify | нет | да, Premium у владельца приложения | каталог и избранное, играет через SoundCloud |
| VK Музыка | да (`vk-worker.js`) | да | экспериментально, VK часто блокирует вход |

Воркеры нужны потому, что сервисы не пускают браузер к своему API напрямую (CORS) или требуют заголовки, которые браузер не умеет ставить.

## Установка

1. Выложите файлы `index.html`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png` на любой статический хостинг с HTTPS:
   - **Cloudflare Pages:** подключите репозиторий, команда сборки пустая, папка вывода `/`.
   - **GitHub Pages:** Settings → Pages → ветка `main`, папка `/ (root)`.
2. Откройте адрес сайта. В меню браузера выберите «Установить приложение».

После изменения `index.html` увеличьте номер версии кэша в `sw.js` (`const C='mp-v14'`), иначе браузер может показывать старую версию.

## Как создать воркер Cloudflare

Для Яндекса, SoundCloud и VK шаги одинаковые, меняется только файл с кодом.

1. Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Create Worker.
2. Дайте имя и нажмите Deploy.
3. Нажмите Edit code, удалите шаблон, вставьте код нужного файла и снова нажмите Deploy.
4. Скопируйте адрес вида `https://имя.аккаунт.workers.dev`. Он понадобится в плеере.

Не публикуйте адрес воркера: он открыт для запросов с любого сайта.

## Подключение сервисов

Всё подключается в плеере: **Настройки → Сервисы**.

### SoundCloud

1. Создайте воркер из файла `sc-worker.js` (см. выше).
2. Откройте адрес воркера в браузере. Должно быть `{"ok":"sc-worker"}`. Проверить поиск можно адресом `…/sc/search?q=test`.
3. В плеере: Сервисы → SoundCloud → «Указать адрес шлюза», вставьте адрес и нажмите «Включить».
4. Рекомендации: Настройки → Лента → «Источники рекомендаций» → включите SoundCloud. Плеер берёт треки, похожие на ваши избранные, а если таких нет, чарт «в тренде».

SoundCloud не даёт публичный ключ API, поэтому воркер сам берёт `client_id` из скриптов его сайта. Если SoundCloud сменит схему или заблокирует IP Cloudflare, поиск перестанет работать.

### Spotify

Spotify сам в браузере не играет без своего SDK, поэтому плеер использует его как каталог: поиск и ваши сохранённые треки. Воспроизведение идёт через SoundCloud, поэтому **сначала подключите SoundCloud**. Версия трека может отличаться от оригинала.

1. Зайдите на [developer.spotify.com/dashboard](https://developer.spotify.com/dashboard) и создайте приложение. Для этого нужен аккаунт **Spotify Premium**.
2. Откройте в плеере Сервисы → Spotify. В карточке написан **Redirect URI**: скопируйте его в настройки приложения Spotify символ в символ. Адрес должен быть HTTPS (или `http://127.0.0.1:порт` для локальной проверки, `localhost` не принимается).
3. В настройках приложения выберите Web API и в разделе User Management добавьте свой аккаунт Spotify.
4. Скопируйте Client ID, в плеере нажмите «Указать Client ID», затем «Войти в Spotify».
5. После входа заработает поиск по Spotify и кнопка «Мои треки».

Ограничения Spotify для приложений в режиме разработки: до 5 пользователей, в поиске не более 10 результатов. Секретный ключ не нужен: используется вход PKCE.

### Яндекс Музыка

1. Создайте воркер из файла `worker.js`.
2. В плеере: Сервисы → Яндекс Музыка → «Указать адрес шлюза».
3. Нажмите «Войти через Яндекс», откройте `ya.ru/device`, войдите в Яндекс и введите код из плеера.

### YouTube

Поиск работает тремя способами, в Сервисах можно настроить любой:

- **Свой воркер** (рекомендуется): создайте воркер, укажите адрес в «Поиск по YouTube → Свой воркер».
- **Сервер Piped:** укажите адрес своего или рабочего публичного Piped API. Публичные серверы часто блокируются.
- **Ключ YouTube Data API v3:** кнопка «Ключ YouTube API».

Для скачивания можно указать адрес и ключ Cobalt (необязательно).

### VK Музыка (экспериментально)

VK ограничивает сторонние клиенты, поэтому вход может не получиться. Попробовать можно так:

1. Создайте воркер из файла `vk-worker.js` и укажите его адрес в Сервисах → VK Музыка.
2. Нажмите «Войти через VK», введите логин и пароль. Двухфакторный код и подтверждение входа делаются на странице VK, ссылка на неё появится в окне входа.
3. Если VK пишет про «слишком много попыток» или «подозрительный вход», подождите несколько часов и не повторяйте вход. Можно получить токен скриптом `vk_token.py` на своём компьютере (`python vk_token.py`) и вставить его кнопкой «Вставить токен».

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Старый интерфейс после обновления | Увеличьте версию кэша в `sw.js`, обновите страницу дважды |
| «Шлюз не отвечает» | Адрес воркера указан верно, воркер задеплоен (Deploy) |
| SoundCloud: ошибка 502 или 403 | Воркер не смог получить ключ или SoundCloud заблокировал IP, подождите и повторите |
| Трек пропускается сразу | В сообщении указан сервис: проверьте его подключение в Сервисах |
| Spotify: Invalid redirect URI | Адрес в приложении Spotify отличается от показанного в плеере, в том числе слэшем в конце |
| Spotify: 403 при поиске | Ваш аккаунт не добавлен в User Management |

## Важно

Проект неофициальный и не связан с перечисленными сервисами. Он рассчитан на личное использование: соблюдайте условия сервисов и авторские права. Пароли нигде не сохраняются, в браузере хранятся только токены и настройки.
